## 인수 조건 (핵심 3건)

- FR-004: Given 접수 마감일이 오늘인 대회가 있을 때, When 홈의 접수중 섹션을 열면, Then 해당 카드에 "오늘 마감"이 표시된다.
- FR-009/010: Given 대회가 있는 날짜 셀이 있을 때, When 셀을 클릭하면, Then 그 날짜의 대회 카드가 하단에 나타난다.
- FR-008: Given 결과가 30건을 넘을 때, When "대회 더보기"를 누르면, Then 다음 건이 목록 끝에 이어서 추가된다(추가 건수는 미확인).
