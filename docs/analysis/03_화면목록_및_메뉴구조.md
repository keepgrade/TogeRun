# 화면 목록 및 메뉴 구조 (런조아)

## 메뉴 트리

```text
GNB: 검색 / 리스트 / 캘린더 / 지도 / 블로그  (+ 모바일 메뉴 열기 버튼)
├─ 홈 (/)
├─ 서비스
│   ├─ 마라톤 찾기 (/marathon-search)
│   ├─ 마라톤 리스트 (/marathon-list)
│   ├─ 마라톤 캘린더 (/marathon-calendar)
│   └─ 마라톤 지도 (/marathon-map)
├─ 대회 상세 (/marathon/{slug})
├─ 소식: 공지사항(/new?type=notice) · 업데이트(/new?type=updates) · 뉴스레터(/newsletter) · 블로그(/blog)
├─ 지원: 등록문의 · 문의사항 · 불편신고 · 수정요청 (/support?type=registration|inquiry|complaint|correction)
├─ 정책: 소개(/about) · 운영정책(/policy) · 이용약관(/terms) · 개인정보처리방침(/privacy)
└─ 아카이브: 연도별 대회(/marathon-year) · 주소 좌표 변환(/geocoder) · 내 캘린더에 추가(/calendar-add) · 사이트 통계(/analytics)
```
