# 런조아(runzoa.com) 탐색 로그

TogeRun 벤치마킹을 위한 읽기 전용 분석입니다. 원문 문구와 이미지는 복사하지 않고 요약했습니다. 폼 제출, 로그인, 가입은 하지 않았습니다.

- 기준일: 2026-10-21
- 도구: Claude 앱 내장 브라우저 (Playwright MCP 미연결)
- robots.txt: 전체 허용, `/admin/`, `/auth/`, `/mypage`만 금지 → 금지 경로는 탐색하지 않음
- 기술 관찰: Next.js(App Router, `_rsc` 요청, Turbopack 청크) 기반. 목록 데이터는 별도 REST/XHR 호출 없이 서버 렌더링으로 내려오는 것으로 보임(추정). 분석 도구는 Google Analytics(gtag)
