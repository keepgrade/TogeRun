# 사용자 플로우 (런조아)

관찰한 화면 이동을 기준으로 그렸습니다. 로그인 이후 흐름은 확인하지 못해 점선과 "(추정)"으로 표시했습니다.

## 1. 대회 탐색에서 접수까지 (핵심)

```mermaid
flowchart TD
  S[홈 SCR-001] --> Q{어떻게 찾을까}
  Q -->|키워드| SR[검색 SCR-002]
  Q -->|비교| LS[리스트 SCR-003]
  Q -->|날짜| CAL[캘린더 SCR-004]
  Q -->|지역| MAP[지도 SCR-005]
  S -->|접수중 카드| D
  SR --> D[대회 상세 SCR-006]
  LS --> D
  CAL -->|날짜 선택| D
  MAP --> D
  D --> EXT[공식 대회 사이트]
  EXT --> REG[외부에서 참가 신청]
  D -->|주소 복사·지도 링크| LOC[네이버 지도·카카오맵]
  D -->|구독하기| NL[뉴스레터 SCR-008]
```

## 2. 접수 시점을 놓치지 않기 (추정)

```mermaid
flowchart TD
  H[홈: 곧 접수 오픈 예정] --> D[대회 상세]
  D -.->|관심 대회 저장| F[(관심 대회)]
  F -.-> AL[접수 시작·마감 알림]
  AL -.-> D
  D --> EXT[공식 사이트 접수]
  D --> CA[내 캘린더에 추가 SCR-017]
  CA -->|현재 베타 안내| X[작동하지 않음]
```

## 3. 정보 오류 제보

```mermaid
flowchart TD
  D[대회 상세에서 오류 발견] --> SUP[고객지원 SCR-010 수정요청 탭]
  SUP --> FORM[이름·이메일·제목·관련 주소·내용 작성]
  FORM --> AGREE[개인정보 동의 체크]
  AGREE --> SUB[문의하기]
  SUB -.-> OP[운영자: 공식 자료 확인 후 수정 (추정)]
  OP -.-> UP[대회 정보 갱신]
```

## 4. 콘텐츠 소비

```mermaid
flowchart LR
  SNS[Instagram] --> D[대회 상세]
  SE[네이버 검색] --> BL[블로그 SCR-009]
  SE --> D
  BL --> D
  NS[공지·업데이트 SCR-007] --- NL2[뉴스레터 SCR-008] --- BL
```

## 5. 관찰된 흐름의 공백 (TogeRun의 기회)

- 대회 상세 이후는 모두 외부 사이트입니다. 같이 갈 사람을 찾거나 참가 의사를 남기는 경로가 없습니다.
- 알림과 캘린더 추가는 완성되지 않았거나 확인되지 않았습니다.
- 커뮤니티는 "준비 중"이라 후기와 팁은 운영자가 쓰는 블로그에 한정됩니다.
