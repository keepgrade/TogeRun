# TogeRun PRD (제품 요구사항 문서)

BRD의 목표를 **제품의 행동**으로 옮깁니다. 해결할 문제는 "혼자 신청하기 망설이는 러너가 같이 나갈 사람을 찾을 곳이 없다"입니다. 기술 선택은 다음 문서(SDD)에서 다룹니다.

이 문서에서 **버디**는 같은 대회에 함께 나가거나 함께 뛰는 사람을 뜻합니다.

## 1. 사용자 스토리

| ID | 사용자 | 하고 싶은 것 | 이유 |
| --- | --- | --- | --- |
| US-01 | 러너 | 대회를 지역·종목·시기로 찾는다 | 나에게 맞는 대회를 빨리 고르려고 |
| US-02 | 러너 | 관심 대회를 저장하고 접수 알림을 받는다 | 접수 시작을 놓치지 않으려고 |
| US-03 | 러너 | 대회 상세에서 접수 일정과 모집 현황을 본다 | 같이 갈 사람이 있는지 바로 알려고 |
| US-04 | 러너 | 조건이 맞는 모집글에 연락한다 | 혼자 가지 않으려고 |
| US-05 | 러너 | 대회를 정해 모집글을 올린다 | 맞는 글이 없을 때 직접 구하려고 |
| US-06 | 러너 | 모집이 끝난 글을 마감 처리한다 | 불필요한 연락을 받지 않으려고 |
| US-07 | 러너 | 부적절한 글과 사용자를 신고·차단한다 | 낯선 사람과의 접촉이 안전하도록 |
| US-08 | 운영자 | 대회 정보를 입력·수정하고 제보를 처리한다 | 정보를 정확하게 유지하려고 |
| US-09 | 러너 | 다녀온 대회에 별점과 후기를 남긴다 | 다음 사람이 대회를 고르는 데 도움이 되도록 |
| US-10 | 러너 | 대회 상세에서 다른 러너의 리뷰를 본다 | 신청 전에 코스·운영·접근성을 알려고 |
| US-11 | 러너 | 대회별 커뮤니티에 질문하고 정보를 나눈다 | 대회에 대해 궁금한 점을 같은 대회에 나가는 사람에게 물으려고 |
| US-12 | 운영자 | 리뷰와 커뮤니티 글·댓글의 신고를 처리한다 | 부적절한 글과 개인정보 노출을 막으려고 |
| US-13 | 러너 | 내 성별, 나이, 러닝 페이스, 마라톤 경험을 프로필에 적고 공개할 항목을 고른다 | 함께 뛸 버디에게 나를 알리되 원하지 않는 정보는 숨기려고 |
| US-14 | 러너 | 모집글 작성자의 공개 프로필을 본다 | 페이스와 경험이 맞는 사람인지 연락 전에 판단하려고 |
| US-15 | 러너 | 대회를 마라톤·트레일러닝, 국내·해외로 나눠 본다 | 내가 찾는 종류의 대회만 빠르게 보려고 |
| US-16 | 러너 | 해외 주요 대회를 보고 함께 갈 버디를 찾는다 | 항공·숙소·현지 이동이 막막한 해외 대회에 혼자 가지 않으려고 |
| US-17 | 러너 | 트레일 대회의 상승고도, 제한 시간, 필수 장비를 본다 | 신청 전에 난이도와 준비물을 알려고 |
| US-18 | 러너 | 내가 쓰는 소셜 계정으로 로그인한다 | 별도 가입 없이 바로 쓰려고 |

| FR-30 | 트레일러닝 대회는 누적 상승고도, 제한 시간, 난이도, 필수 장비를 표시하고 안전 안내를 함께 보여 준다 (항목은 3-5) | MVP |

| FR-34 | 소셜 로그인으로 가입·로그인한다. 수단은 카카오·Google·네이버를 기본으로 하고, 인스타그램 로그인은 계정 유형 제약이 있어 7장의 열린 질문으로 둔다. 소셜 계정의 이름·아이디·사진은 공개하지 않고 익명 닉네임만 쓴다 | MVP |

관심 대회 저장, 알림, 모집글·리뷰·커뮤니티 글·댓글 작성에는 로그인이 필요합니다. 대회 정보, 모집글, 리뷰, 커뮤니티 글은 로그인 없이 볼 수 있습니다. 로그인 수단은 FR-34를 따릅니다.

## 3. 모집글·리뷰·커뮤니티·프로필 양식과 대회 정보 항목

### 3-1. 모집글 양식

| 항목 | 필수 | 입력 방식 |
| --- | --- | --- |
| 대회 | 필수 | 대회 상세에서 자동 연결 |
| 종목 | 필수 | 선택. 해당 대회에 있는 종목만 고른다 (5K·10K·하프·풀, 트레일은 20K·50K·100M 등) |
| 버디 방식 | 필수 | 선택. 기본값은 **현장 합류**, 그 외 같이 이동, 페이스 맞춰 같이 완주 |
| 모집 인원 | 필수 | 숫자 |
| 모집 마감일 | 필수 | 날짜 선택. 기본값은 대회 접수 마감일이며, 대회일 이후는 고를 수 없다 |
| 출발 지역 | 필수 | 선택 |
| 연락 방법 | 필수 | 오픈채팅 링크 |
| 목표 기록·페이스 | 선택 | 입력 |
| 한 줄 소개 | 선택 | 짧은 텍스트 |

목록에서는 `하프` `현장 합류` `수원`처럼 뱃지로 보여 줘서 글을 열지 않아도 맞는지 판단하게 합니다. 해외·트레일 대회의 글에는 `해외` `트레일` 뱃지가 더해집니다.

해외 대회의 모집글도 같은 양식을 씁니다. 버디 방식의 **같이 이동**에는 항공·숙소·현지 이동을 함께 알아보는 경우가 포함되고, 출발 지역은 국내 출발지를 고릅니다. 금전 거래는 모집 목적이 아니며 신고 대상입니다.

모집 마감일이 지나면 글은 자동으로 모집 완료가 되고, 목록은 기본으로 모집 중인 글만 보여 줍니다. 작성자는 마감일 전에도 직접 마감 처리할 수 있습니다.

모집 조건으로 성별 같은 개인 속성은 받지 않고, 성별·나이로 모집글을 거르는 필터도 두지 않습니다. 처음 만나는 사람끼리 연결되는 서비스라 안전과 차별 우려가 있어서입니다. 성별·나이는 3-4의 프로필에 회원이 선택해 적는 정보일 뿐, 모집글의 조건이나 필터로는 쓰지 않습니다.

### 3-2. 리뷰 양식

| 항목 | 필수 | 입력 방식 |
| --- | --- | --- |
| 대회 | 필수 | 대회 상세에서 자동 연결. 대회일 이후에만 작성할 수 있다 |
| 참가 종목 | 필수 | 선택. 해당 대회에 있는 종목만 고른다 |
| 참가 여부 | 필수 | "참가했어요" 확인 체크 (참가 증빙은 받지 않는다) |
| 종합 별점 | 필수 | 1~5점 |
| 항목별 별점 | 선택 | 코스·운영·접근성(교통·주차)·기념품 각 1~5점 |
| 후기 | 필수 | 텍스트 |

한 사람이 한 대회에 리뷰를 하나만 쓰고, 이후에는 수정으로 고칩니다. 리뷰는 대회 정보 오류 제보(FR-13)와 구분합니다. 정보가 틀렸다면 리뷰가 아니라 제보로 안내합니다. MVP에서는 텍스트만 받고 사진은 2차입니다(FR-25).

### 3-3. 커뮤니티 글 양식

| 항목 | 필수 | 입력 방식 |
| --- | --- | --- |
| 대회 | 필수 | 대회 상세에서 자동 연결 |
| 말머리 | 필수 | 선택. 예: 질문, 정보·팁, 이동·주차, 잡담 |
| 제목 | 필수 | 짧은 텍스트 |
| 본문 | 필수 | 텍스트 |

댓글은 로그인한 사용자가 글에 답니다. 같이 갈 사람을 구하는 글은 커뮤니티가 아니라 모집글로 쓰도록 목록 상단에서 안내합니다. 모집글은 오픈채팅 연결과 마감 처리가 있는 별도 기능이기 때문입니다. 리뷰와 커뮤니티 글에는 연락처 같은 개인정보를 적지 않도록 작성 화면에서 안내합니다.

### 3-4. 러닝 프로필 양식

| 항목 | 필수 | 입력 방식 | 공개 기본값 |
| --- | --- | --- | --- |
| 닉네임 | 필수 | 익명 닉네임 | 공개 |
| 성별 | 선택 | 선택 (여성·남성·밝히지 않음) | 비공개 |
| 나이 | 선택 | 입력 방식은 열린 질문 참고 (연령대 또는 출생연도) | 비공개 |
| 러닝 페이스 | 선택 | km당 분·초 입력 또는 구간 선택 | 공개 |
| 마라톤 경험 기록 | 선택 | 대회별 기록을 여러 건 추가 | 공개 |

마라톤 경험 기록 한 건은 다음 항목으로 이루어집니다.

| 항목 | 필수 | 입력 방식 |
| --- | --- | --- |
| 대회 | 필수 | TogeRun의 대회에서 고르거나 이름을 직접 입력 |
| 참가 연도 | 필수 | 연도 선택 |
| 종목 | 필수 | 선택 (5K·10K·하프·풀·트레일 거리·기타) |
| 완주 여부 | 필수 | 완주·기권 중 선택 |
| 기록 | 선택 | 시:분:초 |
| 메모 | 선택 | 짧은 텍스트 |

경험 기록은 회원이 스스로 적는 값이 기본이며, 기록증·결과 화면 사진을 올려 운영자 확인을 받으면 "인증됨"이 붙습니다(FR-35). 인증 전 기록은 TogeRun이 검증하지 않습니다. 공개 항목은 모집글 상세와 리뷰·커뮤니티 글의 작성자 영역에 보이고, 비공개 항목은 본인만 봅니다. 실명과 연락처는 프로필에 두지 않습니다.

### 3-5. 대회 정보 항목 (종류·범위별)

## 7. 열린 질문

- 로그인 수단: 카카오를 우선 검토한다. 인스타그램 로그인은 Meta 문서 기준으로 프로페셔널(비즈니스·크리에이터) 계정만 지원하고 일반 개인 계정은 대상으로 언급되지 않아, 일반 러너의 로그인 수단으로는 어렵다. 다른 계정을 대신 처리하려면 앱 심사와 사업자 인증이 필요하다
- 인스타그램을 유입 채널로 쓰기 위한 기능 (모집글·대회 페이지의 공유 링크와 공유 카드 이미지, 프로필에 인스타그램 아이디를 선택 항목으로 두는 것. 연락처를 공개하지 않는다는 원칙과 충돌할 수 있어 기본은 비공개로 검토)
- 해외 대회 데이터의 확보·검수 방식(공식 출처, 번역, 접수 방식이 추첨제인 경우의 표기)과 환율 기준·갱신 주기
- 해외 대회 버디의 안전 기준 (여권·항공권 등 정보 공유 범위, 숙소 비용 분담 같은 금전 문제의 처리)
- 트레일 대회의 안전 안내 기준 (필수 장비 목록의 출처, 제한 시간 표기 방식)
- 거리 표기 단위 (km와 마일 병기 여부)
- 알림 채널(푸시, 알림톡, 이메일)과 알림 시점
- 추첨 대회의 **당첨 발표일**을 알림 날짜에 추가할지
- 대회 종료 후 모집방과 커뮤니티 처리 (읽기 전용으로 둘지. 모집글은 모집 마감일 기준으로 마감된다)
- 대회가 매년 열릴 때 리뷰·커뮤니티를 회차별로 나눌지, 한 대회에 이어서 쌓을지
- 리뷰의 참가 여부를 자기 신고로만 받을지, 인증(기록증, 참가 확인 등)을 둘지
- 신고가 몇 건 쌓이면 글을 자동으로 숨길지
- 나이를 연령대로 받을지 출생연도로 받을지, 미성년 가입자의 프로필 처리
- 성별·나이 같은 개인정보의 수집 동의 문구와 보관 기간
- 커뮤니티 말머리의 종류
- 모집 마감일 기본값을 접수 마감일로 둘지, 대회 전날로 둘지 (접수 마감 뒤에도 현장 합류를 모집하는 경우)
- 대회 정보 변경을 반영하는 기준 시간
