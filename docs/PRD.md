# TogeRun PRD (제품 요구사항 문서)

BRD의 목표를 **제품의 행동**으로 옮깁니다. 해결할 문제는 "혼자 신청하기 망설이는 러너가 같이 나갈 사람을 찾을 곳이 없다"입니다. 기술 선택은 다음 문서(SDD)에서 다룹니다.

## 1. 사용자 스토리

| ID | 사용자 | 하고 싶은 것 | 이유 |
| --- | --- | --- | --- |
| US-01 | 러너 | 대회를 지역·종목·시기로 찾는다 | 나에게 맞는 대회를 빨리 고르려고 |
| US-02 | 러너 | 관심 대회를 저장하고 접수 알림을 받는다 | 접수 시작을 놓치지 않으려고 |
| US-03 | 러너 | 대회 상세에서 접수 일정과 모집 현황을 본다 | 같이 갈 사람이 있는지 바로 알려고 |
| US-04 | 러너 | 조건이 맞는 모집글에 연락한다 | 혼자 가지 않으려고 |
| US-05 | 러너 | 대회를 정해 모집글을 올린다 | 맞는 글이 없을 때 직접 구하려고 |
| US-06 | 러너 | 모집이 끝난 글을 마감 처리한다 | 불필요한 연락을 받지 않으려고 |
| US-07 | 러너 | 부적절한 글과 사용자를 신고·차단한다 | 낯선 사람과의 접촉이 안전하도록 |
| US-08 | 운영자 | 대회 정보를 입력·수정하고 제보를 처리한다 | 정보를 정확하게 유지하려고 |

## 2. 기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-01 | 대회 목록에 이름, 일시, 장소·지역, 종목(5K·10K·하프·풀), 참가비, 접수 기간을 표시한다 | MVP |
| FR-02 | 지역·종목·시기로 대회를 필터링한다 | MVP |
| FR-03 | 캘린더에서 대회 일정을 본다 | MVP |
| FR-04 | 접수 오픈일, 접수 마감일, 대회일을 각각 구분해 표시하고 D-day를 따로 계산한다 | MVP |
| FR-05 | 관심 대회를 저장한다 | MVP |
| FR-06 | 저장한 대회의 접수 오픈 전과 마감 임박 시점에 알림을 보낸다 | MVP |
| FR-07 | 대회 일정을 내 캘린더에 추가할 수 있다 | MVP |
| FR-08 | 대회 상세에 관심 러너 수와 모집 중인 글 수를 표시한다 | MVP |
| FR-09 | 대회 상세에서 모집글을 작성한다 (양식은 3장) | MVP |
| FR-10 | 모집글 목록에서 종목·지역·동행 방식으로 필터링한다 | MVP |
| FR-11 | 연락은 작성자가 입력한 오픈채팅 링크로만 연결한다 | MVP |
| FR-12 | 모집글과 사용자를 신고·차단한다 | MVP |
| FR-13 | 사용자가 대회 정보 오류를 제보하고 대회 등록을 문의한다 | MVP |
| FR-14 | 운영자가 대회 정보와 모집글을 관리한다 | MVP |
| FR-15 | 러닝 프로필(완주 횟수, 참가 이력, 페이스)을 보여준다 | 2차 |
| FR-16 | 동행 후 후기와 매너 평가를 남긴다 | 2차 |
| FR-17 | 자체 채팅을 제공한다 | 2차 |
| FR-18 | 지역·종목·페이스 기반 대회·동행을 추천한다 | 3차 |

관심 대회 저장, 알림, 모집글 작성에는 로그인이 필요합니다.

## 3. 모집글 양식

| 항목 | 필수 | 입력 방식 |
| --- | --- | --- |
| 대회 | 필수 | 대회 상세에서 자동 연결 |
| 종목 | 필수 | 선택 (5K·10K·하프·풀) |
| 동행 방식 | 필수 | 선택. 기본값은 **현장 합류**, 그 외 같이 이동, 페이스 맞춰 같이 완주 |
| 모집 인원 | 필수 | 숫자 |
| 출발 지역 | 필수 | 선택 |
| 연락 방법 | 필수 | 오픈채팅 링크 |
| 목표 기록·페이스 | 선택 | 입력 |
| 한 줄 소개 | 선택 | 짧은 텍스트 |

목록에서는 `하프` `현장 합류` `수원`처럼 뱃지로 보여 줘서 글을 열지 않아도 맞는지 판단하게 합니다.

## 4. 화면 요구사항

| 화면 | 포함 요소 |
| --- | --- |
| 홈 | 접수 임박 대회(D-day), 이번 달 대회, 모집 중인 동행 |
| 대회 목록·캘린더 | 필터, 대회 카드, 카드의 [같이 뛸 사람 구하기] 버튼, 관심 러너 수 |
| 대회 상세 | 대회 정보, 세 가지 날짜(접수 오픈·접수 마감·대회일), 모집글 목록, 모집글 작성 버튼 |
| 모집글 작성 | 3장의 양식 |
| 내 정보 | 저장한 대회, 내 모집글, 차단 목록 |

## 5. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 개인정보 | 실명과 연락처는 공개하지 않고, 익명 닉네임과 출발 지역만 보여 준다 |
| 알림 | 접수 오픈 시각 전에 도착해야 한다 (시점은 미정) |
| 사용 환경 | 알림을 받고 바로 여는 사용을 고려해 모바일 화면을 우선한다 |
| 저작권 | 대회 공식 이미지와 타 서비스의 문구·디자인은 사용하지 않는다 |
| 안전 | 운영 규칙을 대회 모집방 상단에 고정한다 |

## 6. 수락 기준

"된다"의 기준을 Given-When-Then으로 적습니다.

| ID | 관련 | Given | When | Then |
| --- | --- | --- | --- | --- |
| AC-01 | FR-06 | 로그인한 사용자가 대회를 저장하고 알림을 켰다 | 접수 오픈 시각이 다가온다 | 접수 오픈 전에 알림을 받는다 |
| AC-02 | FR-04 | 접수 오픈일·마감일·대회일이 서로 다른 대회가 있다 | 대회 상세를 연다 | 세 날짜가 각각 구분돼 보이고 D-day가 따로 계산된다 |
| AC-03 | FR-09 | 로그인한 사용자가 대회 상세에서 모집글 작성을 눌렀다 | 필수 항목을 모두 입력해 등록한다 | 해당 대회 모집글 목록에 글이 보이고 대회가 자동 연결돼 있다 |
| AC-04 | FR-09 | 모집글 작성 중이다 | 필수 항목이 비어 있는 채 등록한다 | 등록되지 않고 비어 있는 항목이 안내된다 |
| AC-05 | FR-10 | 모집글이 여러 개 있다 | 종목과 지역 필터를 선택한다 | 조건에 맞는 글만 보인다 |
| AC-06 | FR-11 | 모집글 목록과 상세를 본다 | 글을 확인한다 | 닉네임, 출발 지역, 오픈채팅 링크 외 개인 정보는 보이지 않는다 |
| AC-07 | FR-12 | 사용자가 모집글을 보고 있다 | 신고한다 | 운영자 확인 대상으로 접수되고 신고자는 작성자를 차단할 수 있다 |
| AC-08 | US-06 | 작성자가 자신의 모집글을 열었다 | 마감 처리한다 | 목록에서 모집 완료로 표시된다 |

## 7. 열린 질문

- 로그인 수단
- 알림 채널(푸시, 알림톡, 이메일)과 알림 시점
- 추첨 대회의 **당첨 발표일**을 알림 날짜에 추가할지
- 모집글 유효기간과 대회 종료 후 모집방 처리
- 대회 정보 변경을 반영하는 기준 시간
