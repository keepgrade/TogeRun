## 1. 레퍼런스 분석 요약

### 1-1. 런조아 게시글의 공통 구조
| 순서 | 블록 | 내용 |
|---|---|---|
| 1 | 제목 | 국기/이모지 + 대회명 (+ 해외·이벤트 성격 표시) |
| 2 | 훅 | 1~2줄 감성 카피 (예: "오페라하우스에서 완주하는 마라톤!") |
| 3 | 대회 일정 | 날짜(요일), 집결/출발 시각 |
| 4 | 장소 | 출발·도착 지점, 도시, 주차 등 |
| 5 | 종목 및 참가비 | 종목별 가격, 정원, 제한시간 |
| 6 | 접수 안내 | 접수 기간(시각까지), 선착순/추첨, 접수처 |
| 7 | 참가 혜택·안내 | 기념품, 연령 제한, 반입 금지 등 주의사항 |
| 8 | 특징 | 이 대회만의 포인트 4~5개 (체크/이모지 불릿) |
| 9 | 확인 고정 문구 | "최신 접수 정보는 공식 홈페이지에서 반드시 확인해 주세요" |
| 10 | 브랜드 푸터 + CTA | 서비스 소개 4줄 + 프로필 링크 유도 |
| 11 | 해시태그 | 6개 안팎, 마지막은 브랜드 태그 |

### 1-2. 효과를 내는 요소
- **섹션마다 이모지 머리말**을 고정해 스캔하기 쉽다 (일정, 장소, 참가비, 접수).
- **접수 일정은 "시각"까지** 적는다. 선착순, 마감 임박, 조기 마감 같은 경고로 행동을 유도한다.
- **정보 게시글의 가치는 정확성**이다. 마지막에 공식 확인 문구를 고정한다.
- **게시 시점이 중요하다.** 접수 오픈 직전이나 당일에 올린다 (굿바이 잠실은 접수 당일에 올렸다).
- **대회 유형을 구분한다.** 해외 대회, 이벤트 페스티벌, 기부 러닝, 기념 대회 등 유형마다 훅이 다르다.
- 캡션 본문이 길어도 괜찮다. 핵심은 카드뉴스에 요약하고 캡션은 검색용 상세로 둔다.

### 1-3. 투게런의 차별 포인트
런조아는 **일정 정보**가 중심이다. 투게런은 같은 정보 구조 위에 **함께 뛰는 경험**을 얹는다.
1. **버디 연결:** "이 대회 같이 뛸 사람?" → 앱의 버디 모집으로 연결
2. **후기:** 지난 대회 후기 한 줄 인용 (후기가 있는 대회에 한함)
3. **초보자 시선:** "처음 나가도 괜찮은 대회인가?" 한 줄 평가

## 2. 정보 작성 원칙 (필수)

1. **사실 정보는 공식 출처에서 확인한다.** 공식 홈페이지나 접수처 공지를 기준으로 하고, 다른 계정이나 커뮤니티 글은 참고용이다. 레퍼런스 계정 글에서 숫자를 그대로 가져와 올리지 않는다.
2. **문장은 새로 쓴다.** 날짜, 장소, 금액 같은 사실은 같아도 되지만 표현, 훅 카피, 특징 문구는 투게런의 말로 다시 쓴다. 문단 복사는 금지다.
3. **불확실하면 적지 않는다.** 확인하지 못한 항목은 "공식 공지 확인 필요"로 두고 게시 전에 채운다. 추측으로 채우지 않는다.
4. **접수 일정은 한국 시각(KST)과 요일까지** 쓴다. 해외 대회는 현지 시각과 한국 시각을 구분한다.
5. **게시 직전에 접수 상태를 다시 확인한다.** (마감, 일정 변경, 정원 마감)
6. **출처를 남긴다.** 노션 캘린더 항목에 공식 URL과 확인한 날짜를 적는다.
7. 대회 공식 이미지나 포스터는 허락 없이 쓰지 않는다. 카드뉴스는 투게런이 직접 만든 디자인으로 제작한다. 협업이나 허락이 있으면 그 사실을 기록한다.

## 3. 캡션 템플릿

`[ ]`는 채울 곳이고, 해당 없는 블록은 통째로 삭제한다. 이모지는 아래를 고정 사용한다.

```
[국기/이모지] [대회명]

[훅 카피 1~2줄: 이 대회를 한 문장으로]

📅 대회 일정
[날짜(요일)] · [집결/출발 시각]

📍 장소
[출발지 → 도착지] · [도시]

🏃 종목 · 참가비
[종목] [가격] (정원 [N]명 / 제한시간 [시간])

🔥 접수 안내
[접수 시작 ~ 마감, 시각 포함] · [선착순/추첨]
[접수처 이름]

✨ 이 대회 포인트
· [특징 1]
· [특징 2]
· [특징 3]

⚠️ 참가 전 확인
· [연령/반입 금지/취소 마감 등 주의점]

📌 최신 접수 정보는 공식 홈페이지에서 꼭 확인해 주세요.

🤝 이 대회 같이 뛸 사람이 필요하다면?
투게런에서 러닝 버디를 찾아보세요. (프로필 링크)

.
.
.
[해시태그]
```

### 작성 규칙
- 첫 줄(제목+훅)이 피드 미리보기에 보이므로 **대회명과 가장 강한 포인트**를 거기에 둔다.
- 불릿은 최대 5개, 한 줄 30자 안팎으로 쓴다.
- 접수 기간이 임박한 대회(7일 이내)는 훅 앞에 `⏰ 접수 마감 D-n`을 붙인다.
- 버디 CTA 블록은 **모든 대회 게시글에 고정**한다. 이것이 투게런의 차별점이다.
- 광고성 과장 표현(최고, 무조건, 역대급)은 쓰지 않는다. 사실 + 가볍고 친근한 말투를 지킨다.

## 4. 해시태그 규칙 (총 6~8개)

| 구성 | 개수 | 예시 |
|---|---|---|
| 대회명 (한글) | 1 | #[대회명] |
| 대회명 (영문, 해외·국제 대회) | 0~1 | #[EventName] |
| 지역/종류 | 1~2 | #[지역]마라톤 #10K #하프마라톤 |
| 성격 | 1 | #해외마라톤 #기부러닝 #마라톤접수 |
| **브랜드 고유 태그** | 1 | **#함께더멀리** |
| 계정 태그 | 1 | #투게런 |

- 고유 태그 #함께더멀리는 모든 게시글에 붙인다.
- 같은 태그 조합을 반복하지 않는다. 대회명과 지역 태그는 매번 바꾼다.
- 해시태그는 캡션 맨 아래 `.` 구분선 아래에 둔다.

## 5. 카드뉴스 구성 (4:5, 1080×1350)

| 장 | 내용 | 비고 |
|---|---|---|
| 1 | 표지: 대회명 + 훅 + 날짜 | 한눈에 읽히는 큰 글씨 |
| 2 | 일정 · 장소 | 지도/아이콘은 직접 제작 |
| 3 | 종목 · 참가비 | 표 형태 |
| 4 | 접수 안내 (기간·방식·마감 경고) | 마감일 강조 색 |
| 5 | 이 대회 포인트 3개 | |
| 6 | 투게런 CTA: "같이 뛸 버디 찾기" + 링크 안내 | 모든 게시글 공통 |

- 장수는 4~6장으로 하고, 정보가 적으면 줄인다.
- 폰트와 색은 투게런 앱 디자인 토큰을 따른다.
- 모든 장에 작게 @togerun_official 워터마크를 넣는다.

## 6. 게시 시점과 주기

| 상황 | 시점 |
|---|---|
| 접수 오픈 예정 대회 | 오픈 1~3일 전 예고 + 오픈 당일 아침 |
| 접수 중인 대회 | 마감 7일 전, 3일 전 |
| 인기 대회(선착순 마감 빠름) | 오픈 당일 최우선 |
| 해외 대회 | 추첨/접수 시작 2주 전 |
| 월간 정리 | 매월 말 "다음 달 대회 미리보기" |

- 대회 소개 게시글은 **주 2~3회**, 나머지는 러닝 팁, 밈, 버디 모집으로 채운다.
- 우선순위: ① 접수 마감 임박 ② 이번 달 개최 ③ 화제성 ④ 지역 균형

## 7. 게시 전 체크리스트

- [ ] 대회명, 날짜, 요일이 공식 공지와 일치하는가
- [ ] 접수 기간을 시각까지 확인했는가 (KST)
- [ ] 참가비와 정원, 제한시간을 확인했는가
- [ ] 접수 상태(마감 여부)를 게시 당일에 다시 봤는가
- [ ] 레퍼런스 계정의 문장을 그대로 쓰지 않았는가
- [ ] 공식 이미지나 포스터를 허락 없이 쓰지 않았는가
- [ ] 공식 확인 문구와 버디 CTA가 들어갔는가
- [ ] 해시태그 6~8개, #함께더멀리 포함
- [ ] 오탈자, 이모지 깨짐, 링크 안내 확인

## 8. Claude에게 초안을 시키는 방법

아래 형식으로 요청한다.

```
이 가이드라인(docs/instagram/01_대회소개_게시글_가이드라인.md)에 맞춰
[대회명] 인스타 게시글 초안을 써줘.
- 공식 URL: [URL]
- 확인된 정보: [날짜/장소/종목/참가비/접수기간]
- 유형: [해외/이벤트/기부/지역 대회]
```

Claude는 다음을 지킨다.
- 공식 URL의 내용만 사실로 쓰고, 모르는 항목은 `[확인 필요]`로 남긴다.
- 캡션 + 카드뉴스 장별 문구 + 해시태그를 한 번에 낸다.
- 완성본은 노션 콘텐츠 캘린더의 해당 행에 넣을 수 있게 정리한다.

## 9. 하지 않는 것

- 다른 계정 게시글의 복사 후 단어만 바꾸기
- 확인하지 않은 접수 정보 게시
- 대회 주최 측 사진이나 포스터의 무단 사용
- 인플루언서 DM, 맞팔, 좋아요 자동화
- 과장 광고성 표현
