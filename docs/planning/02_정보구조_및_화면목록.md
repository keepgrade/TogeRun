# 정보구조와 화면 목록

[PRD](../PRD.md)의 화면 요구사항을 화면 단위로 나눈 문서입니다. 레퍼런스에서 가져온 구성은 근거를 표시했습니다. 화면ID는 `S-xx`를 씁니다.

## 1. 정보구조(IA)

```text
하단 탭(모바일 우선)
├─ 홈                                   S-01
├─ 대회                                 S-02 목록 / S-03 캘린더
│   └─ 대회 상세 (탭 4개)               S-04
│       ├─ 정보
│       ├─ 같이 뛸 사람 (모집글)
│       │     ├─ 모집글 상세            S-05
│       │     └─ 모집글 작성·수정       S-06
│       ├─ 리뷰
│       │     └─ 리뷰 작성·수정         S-07
│       └─ 커뮤니티
│             ├─ 글 상세 + 댓글         S-08
│             └─ 글 작성·수정           S-09
├─ 알림                                 S-13
└─ 내 정보                              S-11
    ├─ 프로필 편집 + 마라톤 경험 기록   S-12
    ├─ 저장한 대회 / 내 모집글 / 내 리뷰 / 내 글 / 차단 목록
    └─ 알림 설정

공통
├─ 로그인                               S-10
├─ 공개 프로필 보기(시트)               S-15
├─ 신고(시트)                           S-16
└─ 정보 오류 제보·등록 문의             S-14

운영자
└─ 운영자 콘솔                          S-17
```

탭 구성 근거:
- 대회 상세 안에 모집, 리뷰, 커뮤니티를 탭으로 두는 구조는 링커리어 공고 상세(상세·팀원 모집·합격자료·Q&A 탭)에서 가져왔습니다.
- 홈에서 접수 임박·이번 달·접수중으로 나누는 구성은 런조아에서 가져왔습니다.

## 4. 열람과 작성 권한

| 대상 | 로그인 없이 | 로그인 후 |
| --- | --- | --- |
| 대회 정보, 모집글, 리뷰, 커뮤니티 글 | 열람 | 열람 |
| 모집글·리뷰·글·댓글 작성, 관심 저장, 알림 | 불가(로그인으로 안내, 끝나면 원래 화면으로 복귀) | 가능 |
| 오픈채팅 연락 | 제안: 로그인 필요(스팸 방지) | 가능 |
| 신고·차단 | 불가 | 가능 |

로그인 복귀(`next`)와 읽기 개방은 링커리어 방식을 참고했습니다. 오픈채팅 링크를 로그인 후에만 보여 줄지는 아직 정해지지 않은 제안입니다.
