# 사용자 플로우

[PRD](../PRD.md)의 사용자 스토리(US-01~14)를 흐름으로 옮겼습니다. 화면ID는 [02_정보구조_및_화면목록.md](02_정보구조_및_화면목록.md)를 따릅니다.

## 1. 대회를 찾아 접수 알림 받기 (US-01, US-02)

```mermaid
flowchart TD
  A[홈 S-01] --> B[대회 목록 S-02]
  B -->|종류·범위 탭, 지역·종목·시기 필터| B
  B --> C[대회 상세 S-04]
  A -->|접수 임박 카드| C
  C --> D{로그인했나}
  D -- 아니오 --> L[로그인 S-10]
  L -->|원래 화면으로 복귀| C
  D -- 예 --> E[관심 저장]
  E --> F[알림 켜기 S-13]
  F --> G[접수 오픈 전 알림]
  G --> H[공식 사이트에서 접수]
```

## 2. 같이 뛸 사람 찾아 연락하기 (US-03, US-04, US-14)

```mermaid
flowchart TD
  A[대회 상세 S-04] -->|같이 뛸 사람 탭| B[모집글 목록]
  B -->|종목·버디 방식·출발 지역 필터| B
  B --> C[모집글 상세 S-05]
  C --> P[작성자 공개 프로필 S-15]
  P --> C
  C --> D{맞는 사람인가}
  D -- 아니오 --> B
  D -- 예 --> E{로그인했나}
  E -- 아니오 --> L[로그인 S-10]
  L --> C
  E -- 예 --> F[오픈채팅으로 연락하기]
  F --> G[외부 오픈채팅에서 대화]
```

## 3. 모집글 올리고 마감하기 (US-05, US-06)

```mermaid
flowchart TD
  A[대회 상세 S-04] --> B{맞는 모집글이 있나}
  B -- 있다 --> C[연락하기]
  B -- 없다 --> D[모집글 쓰기 S-06]
  D --> V{필수 항목 입력, 마감일 검증}
  V -- 오류 --> D
  V -- 통과 --> E[목록에 노출, 대회 자동 연결]
  E --> F[연락 받음]
  F --> G{인원이 찼나}
  G -- 예 --> H[작성자가 마감 처리]
  G -- 아니오 --> I{모집 마감일 경과}
  I -- 예 --> J[자동 모집 완료]
  I -- 아니오 --> F
  H --> K[목록에서 모집 완료 표시]
  J --> K
```

## 4. 신고·차단 (US-07, US-12)

```mermaid
flowchart TD

  B --> C[사유 선택과 내용 입력]
  C --> D[운영자 큐에 접수]
  C --> E{작성자 차단하기}
  E -- 예 --> F[차단 목록에 추가, 목록에서 숨김]
  D --> G[운영자 확인]
  G --> H{조치}
  H --> I[유지]
  H --> J[숨김·삭제]
  H --> K[사용자 제재]
```
