# 화면명세서

핵심 화면 9개를 상세히 정리했습니다. 나머지(S-03, S-08, S-10, S-11, S-13, S-15~S-17)는 4장의 요약을 참고하세요. 와이어프레임은 텍스트로 그렸고, 모바일 화면을 기준으로 합니다([PRD](../PRD.md)의 모바일 우선 요구). 레퍼런스에서 가져온 부분은 `[런조아]`, `[링커리어]`로 표시했습니다.

공통 규칙
- 날짜는 접수 오픈, 접수 마감, 대회일을 항상 구분해 표시한다(FR-04).
- 상태 뱃지는 대회는 `접수 예정 / 접수중 / 접수 마감 / 종료`, 모집글은 `모집중 / 모집 완료`를 쓴다. `[런조아]`
- 접수 마감 당일은 "오늘 마감", 이후는 "마감 D-N"으로 표기한다. `[런조아]`
- 작성자는 항상 익명 닉네임으로 보인다.
- 로딩, 빈 상태, 오류 상태를 모든 목록에 둔다.

## S-01 홈

```text
┌ 검색(대회명·지역) ┐
├ 접수 임박 (가로 카드, D-day)
├ 모집 중인 버디 (최신 모집글 카드)
├ 이번 달 대회 (개최일순)
└ 하단 탭: 홈 | 대회 | 알림 | 내 정보
```

| 영역 | 내용 | 동작 |
| --- | --- | --- |
| 접수 임박 | 접수 오픈 또는 마감이 가까운 대회 카드(D-day, 접수 상태) | 상세로 이동 |
| 모집 중인 버디 | 대회명, 종목·버디 방식·출발 지역 뱃지, 모집 인원 | 모집글 상세로 이동 |
| 이번 달 대회 | 대회 수와 개최일순 카드 | 상세로 이동, 전체 보기 |

데이터: 현황 카드에는 종류·범위별 대회 수(국내 마라톤, 국내 트레일러닝, 해외 마라톤, 해외 트레일러닝)와 모집 중인 버디 수를 보여 준다. 기본 구획(접수 예정·이번 달·접수중)은 국내 마라톤만 보여 주고, 트레일러닝과 해외 주요 마라톤은 별도 구획으로 둔다(FR-29, FR-32). 현황 카드의 큰 숫자는 모든 종류의 합계라서 눌러 이동하는 목록(기본 선택)과 개수가 다를 수 있다.

## S-02 대회 목록

| 요소 | 내용 |
| --- | --- |
| 종류·범위 탭 | 마라톤/트레일러닝, 국내/해외 두 쌍의 탭. 고른 값은 캘린더·지도로 이동해도 유지(FR-29) `[랭킹마라톤 참고]` |
| 검색 | 대회명·지역·장소·도시 |
| 필터 | 지역(해외는 국가), 종목(고른 종류·범위에 있는 거리만), 시기(월). 접수 상태는 칩으로 빠르게 전환. 종류·범위를 바꾸면 지역·종목·시기 선택은 비운다 |
| 정렬 | 개최일 빠른순(기본), 접수 마감 임박순 |
| 카드 | 대회명, 대회일과 D-day, 장소·지역, 종목, 참가비(해외는 현지 통화와 원화 환산), 접수 상태, 트레일·해외 뱃지, 관심 러너 수, 모집 중 글 수, 평균 별점, [같이 뛸 사람 구하기] |
| 페이징 | 30건 단위, [더보기] 버튼 `[런조아]` |
| 지난 대회 | 기본 제외, 토글로 포함 |

필터는 지역(해외는 국가)·종목·시기 세 가지로 시작하고, 종류와 범위는 필터가 아니라 탭으로 분리한다(FR-02, FR-29). 런조아의 규모 필터는 뺀다.

## S-04 대회 상세

```text
┌ 대회명 / 상태 뱃지
├ 날짜 3종: 접수 오픈 | 접수 마감 | 대회일 (각각 D-day)
├ ♥ 관심 저장 · 캘린더에 추가 · 공식 사이트로 접수
├ ★ 4.3 (리뷰 N) · 같이 뛸 사람 N · 커뮤니티 N
└ 탭: 정보 | 같이 뛸 사람 | 리뷰 | 커뮤니티
```

| 탭 | 내용 |
| --- | --- |
| 정보 | 종목별 참가비, 장소·주소, 주최·주관, 연락처, 주차, 기념품, 메모, 위치 링크(외부 지도), 정보 오류 제보 링크. **트레일**: 누적 상승고도, 제한 시간, 난이도, 필수 장비, 안전 안내(FR-30). **해외**: 국가·도시, 현지 통화 참가비와 원화 환산, 현지 시각 안내(FR-31) |
| 같이 뛸 사람 | 모집글 목록(종목·버디 방식·출발 지역 필터, 모집중만 보기 기본), [모집글 쓰기] |
| 리뷰 | 평균 별점, 항목별 평균, 목록(종목 필터, 최신순·별점순), [리뷰 쓰기](대회일 이후 활성) |
| 커뮤니티 | 말머리 필터, 글 목록, [글쓰기], "같이 갈 사람은 모집글로" 안내 |

규칙
- 접수는 TogeRun에서 하지 않고 공식 사이트로 연결한다. `[런조아]`
- 해외 대회의 접수 일시는 현지 시각이고, 원화 환산은 고정 환율을 쓴 참고용이라고 밝힌다. 입국 서류·항공·숙소는 직접 확인해야 한다는 안내를 붙인다.
- 트레일 대회는 필수 장비와 제한 시간을 지키지 못하면 실격될 수 있다는 안내를 붙인다.
- 탭 위에 보이는 별점·모집·글 수는 탭으로 바로 이동하는 단축 링크다.
- 대회일이 지나면 [모집글 쓰기]는 비활성, [리뷰 쓰기]는 활성이 된다.
- 모집 중인 글이 없으면 첫 모집글을 올리도록 안내한다(콜드 스타트 대응).

## S-05 모집글 상세

```text
┌ [하프] [현장 합류] [수원]  · 모집중 · 마감 D-5
├ 요약 표: 대회 | 종목 | 버디 방식 | 모집 인원 | 출발 지역 | 모집 마감일
├ 목표 기록·페이스 / 한 줄 소개
├ 작성자: 닉네임 · 공개 프로필(페이스, 경험 요약)  [프로필 보기]
├ [오픈채팅으로 연락하기]
└ 신고 · 차단
```

- 요약 표 형태는 `[링커리어]` 모집글 상세의 정형 항목 표를 참고했다.
- 연락은 작성자가 입력한 오픈채팅 링크로만 한다(FR-11). 링크 형식은 작성 시 검증한다.
- 작성자가 보면 [마감 처리], [수정], [삭제]가 보인다.
- 모집 마감일이 지나면 자동으로 `모집 완료`가 되고 연락 버튼이 비활성화된다.

## S-06 모집글 작성·수정

| 항목 | 필수 | 입력 | 비고 |
| --- | --- | --- | --- |
| 대회 | 필수 | 자동 연결 | 대회 상세에서 진입, 변경 불가 |
| 종목 | 필수 | 선택 | 해당 대회의 종목만 노출 |
| 버디 방식 | 필수 | 선택 | 기본 현장 합류 |
| 모집 인원 | 필수 | 숫자 | 1 이상 |
| 모집 마감일 | 필수 | 날짜 | 기본 접수 마감일, 대회일 이후 선택 불가 |
| 출발 지역 | 필수 | 선택 | - |
| 연락 방법 | 필수 | 오픈채팅 링크 | 형식 검사 |
| 목표 기록·페이스 | 선택 | 입력 | - |
| 한 줄 소개 | 선택 | 짧은 텍스트 | 연락처 입력 금지 안내 |

검증: 필수 항목이 비면 등록되지 않고 비어 있는 항목이 안내된다(AC-04). 마감일이 대회일 이후면 선택되지 않는다(AC-09). 성별·나이 항목은 두지 않는다.

## S-07 리뷰 작성·수정

| 항목 | 필수 | 입력 |
| --- | --- | --- |
| 대회 | 필수 | 자동 연결(대회일 이후만 진입 가능) |
| 참가 종목 | 필수 | 선택 |
| 참가했어요 | 필수 | 체크(증빙 없음) |
| 종합 별점 | 필수 | 1~5 |
| 항목별 별점 | 선택 | 코스·운영·접근성(교통·주차)·기념품 각 1~5 |
| 후기 | 필수 | 텍스트 |

이미 리뷰를 쓴 대회에서는 새로 쓰기 대신 수정으로 안내한다(AC-13). 정보가 틀렸다는 내용은 리뷰 대신 제보(S-14)로 안내한다. 사진은 MVP에서 받지 않는다.

## S-09 커뮤니티 글 작성·수정

| 항목 | 필수 | 입력 |
| --- | --- | --- |
| 대회 | 필수 | 자동 연결 |
| 말머리 | 필수 | 선택(예: 질문, 정보·팁, 이동·주차, 잡담) |
| 제목 | 필수 | 텍스트 |
| 본문 | 필수 | 텍스트 |

작성 화면 상단에 "같이 갈 사람 구하기는 모집글로, 연락처 같은 개인정보는 적지 마세요"를 안내한다.

## S-12 프로필 편집

| 항목 | 필수 | 입력 | 공개 기본값 |
| --- | --- | --- | --- |
| 닉네임 | 필수 | 익명 닉네임 | 공개 |
| 성별 | 선택 | 여성·남성·밝히지 않음 | 비공개 |
| 나이 | 선택 | 연령대 또는 출생연도(미정) | 비공개 |
| 러닝 페이스 | 선택 | km당 분·초 또는 구간 | 공개 |
| 마라톤 경험 기록 | 선택 | 대회·연도·종목·완주 여부·기록·메모, 여러 건 | 공개 |

- 항목마다 [공개/비공개] 스위치를 둔다(FR-26).
- 경험 기록은 TogeRun의 대회에서 고르거나 이름을 직접 입력한다. 완주 횟수와 기록한 대회 수는 자동 집계한다(FR-27).
- 모든 선택 항목이 비어 있어도 모집글·리뷰 작성에는 지장이 없다(AC-21).
- 성별·나이 입력 전 수집 목적을 안내하고 동의를 받는다.
- 성별·나이는 모집글 조건이나 필터로 쓰지 않는다는 점을 화면에 밝힌다.

## S-14 정보 오류 제보·등록 문의

`[런조아]`의 문의 폼 구조(이름·이메일·제목·관련 주소·내용·개인정보 동의)를 참고해 줄인다.

| 항목 | 필수 | 입력 |
| --- | --- | --- |
| 유형 | 필수 | 정보 오류 제보 / 대회 등록 문의 |
| 대회 | 오류 제보일 때 필수 | 상세에서 진입하면 자동 연결 |
| 내용 | 필수 | 텍스트 |
| 공식 출처 링크 | 선택(권장) | URL |
| 답변 받을 이메일 | 선택 | 이메일 |
| 개인정보 수집 동의 | 이메일을 쓸 때 필수 | 체크 |

운영 원칙: 공식 자료를 확인한 뒤 반영하고, 주최 측 공지를 우선한다. `[런조아]`

| S-19 대회 지도 | 종류·범위 탭, 접수 상태별 색 마커, 지역(해외는 국가) 칩, 마커 선택 시 요약 카드, 국내 지도와 세계 지도 전환 |

## 5. 상태와 예외

| 상황 | 처리 |
| --- | --- |
| 대회 취소·연기 | 상태에 표시하고, 저장한 사용자에게 알림. 모집글은 자동 마감하지 않고 작성자에게 안내(제안) |
| 모집 마감일 경과 | 자동 모집 완료(AC-10) |
| 대회일 경과 | 모집글 작성 불가, 리뷰 작성 가능 |
| 값 없음 | 참가비·규모가 없으면 "미정"으로 표시 `[런조아]` |
| 차단한 사용자의 글 | 목록에서 숨김 |
| 신고된 글 | 운영자 확인 전까지 노출 유지가 기본. 자동 숨김 기준은 미정 |
