# TogeRun 프론트엔드 PoC

서버 없이 브라우저에서만 도는 프론트엔드 PoC입니다. 기획 문서([PRD](../docs/PRD.md), [기획문서](../docs/planning/))의 핵심 흐름을 화면에서 확인하는 것이 목적입니다.

- 스택: Next.js(App Router) + React + TypeScript + Tailwind CSS + lucide-react
- 데이터: 가상 샘플 데이터. 실제 대회·실제 사용자와 무관합니다. 손으로 쓴 20개 대회에 고정 시드 생성기(`lib/seedGen.ts`)가 만든 44개 대회와 이미 끝난 대회 18개, 사용자 16명, 모집글 52개, 커뮤니티 글 48개와 댓글을 더해 국내 대회 82개와 해외 대회 22개(대회 104개, 끝난 대회 29개), 모집글 약 76개, 커뮤니티 글 약 68개, 댓글, 끝난 대회마다 3~9개씩 쌓인 리뷰(약 150개) 규모입니다. 끝난 대회는 대회 목록의 "지난·취소 대회 포함"을 켜면 볼 수 있습니다. 날짜는 오늘 기준 상대값이라 접수 예정·접수중·마감·종료·취소가 항상 섞여 나옵니다. 생성 규칙을 바꾸면 `lib/types.ts`의 `Data.version`과 `lib/store.tsx`의 `KEY`를 올려 저장된 이전 데이터를 버려야 합니다.
- 저장: 브라우저 `localStorage`(키 `togerun-poc-v1`). 서버·DB·실제 로그인·실제 알림은 없습니다.

## 실행

Node.js 24.11 이상이 필요합니다.

```bash
cd app
npm install
npm run dev
```

http://localhost:3000 을 엽니다. 데이터를 처음 상태로 돌리려면 `내 정보 > 데이터 초기화`를 누르세요.

구현한 규칙(PRD 기준)
- 대회 상태는 날짜로 계산한다: 접수 예정 · 접수중 · 접수 마감 · 종료. 취소는 데이터에 직접 표시한다.
- 모집 마감일 기본값은 접수 마감일, 대회일 이후는 고를 수 없다(AC-09).
- 모집 마감일이 지났거나 대회가 끝났으면 자동으로 모집 완료, 목록은 기본으로 모집중만 보여 준다(AC-10).
- 연락은 `https://open.kakao.com/o/…` 형식의 오픈채팅 링크만 받는다. 한 줄 소개에 전화번호가 있으면 막는다.
- 성별·나이는 모집 조건이나 필터로 쓰지 않는다.

## 아직 없는 것

운영자 콘솔(접수된 신고를 처리하는 화면), 사진 첨부(리뷰·커뮤니티), 자체 채팅, 실제 알림 발송.

## 리뷰

- 대회 상세의 리뷰 탭. 평균 별점과 1~5점 분포, 항목별(코스·운영·접근성·기념품) 평균, 종목 필터, 최신순·별점 높은순·낮은순 정렬.
- 작성은 `/races/[id]/review/new`. **대회가 끝난 뒤에만** 쓸 수 있고(진행 전·취소 대회는 버튼 비활성, 직접 주소로 들어가도 막힘) 로그인이 필요합니다.
- 한 사람이 한 대회에 리뷰 하나만 쓰고, 이미 썼다면 새로 쓰는 대신 기존 리뷰를 수정으로 엽니다(중복 등록 불가).
- 양식: 참가 종목(필수), "참가했어요" 확인(필수, 증빙 없음), 종합 별점(필수), 항목별 별점(선택, 지우기 가능), 후기(필수, 10~1000자, 연락처 차단). 사진은 받지 않습니다.
- 내 리뷰는 수정·삭제할 수 있고, 다른 사람의 리뷰는 신고·작성자 차단을 할 수 있습니다. 차단한 사용자의 리뷰는 목록과 평균에서 빠집니다.
- 정보가 틀렸다는 내용은 리뷰 대신 정보 오류 제보로 안내합니다. 내 정보에서 내가 쓴 리뷰를 모아 봅니다.

## 러닝 프로필

- 편집 화면: `/me/profile` (내 정보에서 진입). 닉네임은 항상 공개이고 실명·연락처는 받지 않습니다.
- 입력 항목은 모두 선택입니다: 성별, 나이(연령대), 러닝 페이스(1km당, 2'30"~15'00"), 마라톤 경험 기록. 비워 둬도 모집글·리뷰를 쓸 수 있습니다.
- 항목마다 공개/비공개를 정합니다. 기본값은 성별·나이 비공개, 페이스·마라톤 경험 공개입니다. 성별·나이는 모집 조건이나 필터로 쓰지 않습니다.
- 성별·나이를 입력하려면 수집·이용 동의가 필요하고, 두 항목을 모두 지우면 동의 체크가 사라집니다.
- 마라톤 경험 기록: 대회(TogeRun 대회 선택 또는 직접 입력), 참가 연도, 종목, 완주/기권, 기록(완주일 때), 메모. 추가·수정·삭제가 되고, 기록한 대회 수와 완주 횟수를 자동 집계합니다. 직접 적는 값이라 검증하지 않습니다.
- 편집 화면 아래의 "다른 사람에게 이렇게 보여요"는 모집글 상세의 작성자 영역과 같은 컴포넌트로 그려, 공개 설정이 반영된 모습을 바로 보여 줍니다.

## 신고·차단

- 신고 대상: 모집글, 커뮤니티 글, 댓글, 사용자. 사유 5종과 자세한 내용을 받고, 같은 대상은 한 번만 신고할 수 있습니다.
- 신고하면서 작성자를 함께 차단할 수 있습니다. 내가 쓴 글에는 신고·차단 버튼이 보이지 않습니다.
- 차단하면 그 사용자의 모집글·글·댓글이 목록에서 숨겨지고, 직접 주소로 들어가면 "차단한 사용자" 안내와 해제 버튼이 나옵니다.
- 차단 목록과 내 신고 내역은 `내 정보`에서 봅니다.
- 접수된 신고는 이 브라우저에만 저장됩니다. 운영자가 처리하는 화면과 자동 숨김 기준은 PoC에 없습니다.

## 홈 디자인 방침

홈의 섹션 순서와 배치는 대회 정보 서비스(런조아)의 홈 구조를 참고했습니다. 문구, 이미지, 로고, 색, 코드는 가져오지 않았고 TogeRun의 것으로 새로 만들었습니다. 버디·커뮤니티 구획은 TogeRun만의 영역입니다.

## 대회 종류와 범위 (마라톤/트레일러닝, 국내/해외)

- 대회는 **종류**(마라톤 / 트레일러닝)와 **범위**(국내 / 해외)로 나뉩니다. 대회 목록·캘린더·지도에 같은 탭이 있고, 선택은 화면을 옮겨도 유지됩니다(세션 저장소, `lib/kind.ts`).
- 해외를 고르면 지역 필터가 "국가"로 바뀌고, 지도는 세계 지도로 바뀝니다. 버디 목록에는 종류·범위 필터가 따로 있습니다.
- 홈: 기본 구획(접수 예정·이번 달·접수중)은 국내 마라톤만 보여 주고, **트레일러닝**과 **해외 주요 마라톤** 구획을 따로 둡니다. 현황 카드에 종류·범위별 대회 수 칩이 있습니다.
- 거리는 `5K·10K·하프·풀`에 한정하지 않고 `20K·30K·50K·100K·100M`까지 담습니다(`Distance`는 문자열).
- 트레일 전용 정보: 누적 상승고도, 제한 시간, 난이도, 필수 장비. 해외 전용 정보: 국가·도시, 참가비 통화, 현지 시각 안내.
- 해외 참가비는 현지 통화와 원화 환산을 함께 보여 줍니다(예: `€190 (약 29만원)`). 환율은 PoC용 고정값(`lib/types.ts`의 `CURRENCY_INFO`)이라 참고용입니다.
- 해외 시드(`lib/seedOverseas.ts`): 도쿄·보스턴·런던·베를린·시카고·뉴욕 등 주요 마라톤 17개와 UTMB 등 트레일 5개. **대회 이름과 개최 시기만 실제를 따랐고 접수 기간·참가비·규모는 샘플입니다.** 화면에도 안내가 표시됩니다.

## 로그인 (PoC)

- 카카오, 인스타그램, Google, 네이버 버튼은 모두 가짜 로그인입니다. 누르면 익명 닉네임이 만들어지고, 같은 버튼으로 다시 들어오면 같은 계정으로 돌아옵니다.
- **실제 서비스에서 인스타그램 로그인은 제약이 큽니다.** Meta 문서 기준으로 인스타그램 로그인(Instagram API with Instagram Login)은 프로페셔널(비즈니스·크리에이터) 계정만 지원하고, 일반 개인 계정은 지원 대상으로 언급되지 않습니다. 다른 계정을 대신 처리하려면 Advanced Access(앱 심사와 사업자 인증)가 필요합니다. 일반 러너의 소셜 로그인은 카카오 등 다른 수단이 현실적이고, 인스타그램은 유입 채널로 쓰는 편이 낫습니다.

## 용어와 메뉴

- 같이 뛸 사람을 찾는 기능의 이름은 **버디**입니다. 화면에서 "동행"이라는 단어는 쓰지 않습니다(모집 중인 버디, 버디 방식 등).
- 상단 메뉴 순서: 대회 → 버디 → 커뮤니티 → 캘린더 → 지도. 모바일 하단 탭은 홈·대회·버디·커뮤니티·알림·내 정보입니다.

## 알림 규칙 (PoC 임시)

알림 시점은 PRD의 열린 질문이라 확정된 값이 아닙니다. PoC는 접수 오픈 1일 전, 마감 2일 전 오전 9시로 계산합니다(`lib/alerts.ts`). 실제 푸시·알림톡·이메일은 발송하지 않고, 언제 도착할지만 화면에 보여 줍니다.

## 지도 연동 방식

- 화면 안의 지도는 OpenStreetMap + Leaflet이며 앱 키가 필요 없습니다(`components/RaceMap.tsx`).
- 카카오맵·네이버 지도는 좌표를 담은 공개 링크로 연동합니다(`lib/maps.ts`). 길찾기도 카카오맵 링크입니다.
- 카카오맵·네이버 지도를 화면 안에 직접 넣으려면 각 사의 개발자 앱 키가 필요합니다. 키를 받으면 `RaceMap`만 교체하면 됩니다.
- 대회 좌표는 가상 샘플이라 해당 지역 근처의 대략적인 값입니다. 실제 서비스에서는 주소를 좌표로 바꾸는 입력 도구가 필요합니다.
- OpenStreetMap 공개 타일 서버는 가벼운 개발 용도로만 쓰세요. 서비스 규모가 되면 별도 타일 제공자나 카카오·네이버 SDK로 바꿔야 합니다.

## 알아둘 점

- 화면 전체를 클라이언트에서만 그립니다(`components/ClientOnly.tsx`). 현재 시각과 `localStorage`에 의존해서 서버 렌더링이 의미 없기 때문입니다. 서버를 붙일 때 이 구조를 다시 정해야 합니다.
- 오픈채팅 링크는 샘플이라 실제로 열리지 않을 수 있습니다.
- 한 브라우저에만 저장되므로 여러 사용자를 흉내 낼 수 없습니다. 다른 사람의 글은 샘플 작성자로 대체했습니다.
- 모집글 양식 입력란에 접근 가능한 이름이 빠져 있습니다(레이블을 `htmlFor`로 연결하지 않음). 접근성 개선 항목입니다.

## 기록 인증 (PoC)

- 프로필의 마라톤 경험 기록에서 완주 기록(시간 입력)에 기록증·결과 화면 사진을 첨부하면 `인증 검토 중`이 되고, 운영자가 승인하면 `인증됨`이 붙습니다. PoC에서는 목록의 "승인·반려" 링크로 운영자 처리를 흉내 냅니다.
- 사진 파일은 저장하지 않고 파일 이름과 상태만 둡니다. 인증된 기록의 대회·연도·종목·결과·시간을 바꾸면 인증이 풀립니다. 공개 프로필에는 `✓ 인증`만 표시됩니다.
