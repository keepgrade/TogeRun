# TogeRun

Marathon companion matching: race schedules, registration alerts, and per-race buddy recruiting.

혼자 신청하기 망설여지는 대회, **같이 뛸 사람**을 그 자리에서 찾는 마라톤 동행 서비스입니다.

## 컨셉

- **대회 정보 위에 동행을 얹는다.** 대회를 보다가 바로 같이 갈 사람을 찾습니다.
- **대회마다 모집방이 있다.** 현장 합류, 같이 이동, 페이스 맞춰 완주 중 원하는 방식으로 모집합니다.
- **접수를 놓치지 않게 알려준다.** 관심 대회의 접수 오픈 전에 알림을 보냅니다.
- **가볍고 안전하게 만난다.** 연락은 오픈채팅 링크로만 하고, 실명과 연락처는 공개하지 않습니다.

> 현재 기획 단계이며, 서비스명은 가칭입니다.
