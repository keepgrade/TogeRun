# TogeRun

Marathon companion matching: race schedules, registration alerts, and per-race buddy recruiting.

대회 정보를 본 그 자리에서 **같이 뛸 사람을 찾는** 마라톤 동행 매칭 웹 서비스입니다.

> **상태: 기획 단계.** 아직 동작하는 코드는 없습니다. 서비스명 TogeRun은 가칭이며, 앱스토어·도메인·상표 중복 확인 전입니다.

## 왜 만드나

혼자 신청하기 망설이는 러너가 대회 정보를 본 그 자리에서 같이 나갈 사람을 찾을 방법이 없습니다. 대회 탐색 서비스는 사용자끼리 연결해 주지 않고, 동행 모집 글은 지역 커뮤니티에 흩어져 일반 글에 묻힙니다. TogeRun은 대회 정보 위에 **대회별 동행 모집방**을 얹어 이 간극을 메웁니다.

## 주요 기능 (MVP 계획)

- **대회 탐색**: 지역·종목(5K·10K·하프·풀)·시기로 찾고, 캘린더로 일정 확인
- **세 가지 날짜**: 접수 오픈일·접수 마감일·대회일을 구분해 표시하고 D-day를 각각 계산
- **접수 알림**: 관심 대회를 저장하면 접수 오픈 전, 마감 임박 시점에 알림
- **동행 모집방**: 대회별 모집글 작성·필터(종목, 출발 지역, 동행 방식 — 현장 합류 / 같이 이동 / 페이스 맞춰 완주)
- **연락은 오픈채팅 링크로**: 실명과 연락처는 저장·공개하지 않음
- **신뢰·안전**: 신고, 차단, 운영 규칙
- **운영자 도구**: 대회 정보 입력·수정, 신고·제보 처리

2차(프로필·후기, 자체 채팅)와 3차(추천) 기능은 MVP 이후로 미뤘습니다.

## 기술 스택 (제안, 확정 전)

| 영역 | 제안 |
| --- | --- |
| 화면·서버 | Next.js (TypeScript) |
| 데이터베이스 | 관리형 PostgreSQL |
| 로그인 | 카카오 로그인 |
| 호스팅 | Vercel |
| 알림 | 이메일 + 캘린더 링크(.ics), 이후 알림톡 검토 |

요금, 무료 한도, 카카오 로그인 심사 조건을 확인한 뒤 확정합니다.
